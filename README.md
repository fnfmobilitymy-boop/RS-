# RS Interiors

家具翻新与室内装潢网站。根据用户上传的 9 秒参考视频实现中央图片随滚动扩展、固定导航、错位图片、滚动揭示、固定背景视差、材质节点渐变与大字过渡。参考视频不足以确定原站全部交互，未声称逐帧一致。

## 运行

需要 Node.js 18+，无第三方运行依赖。

```sh
cd /workspace/RS-
npm run dev
```

默认端口 3000，可使用 `PORT` 覆盖。`npm run check` 检查 JavaScript 语法。

## 替换内容

- `public/images/` 中为开发阶段替代图片，非公司的实际项目。图片取自公开示例库 codewithsadee/woodex 和 codewithsadee/realvine；这些示例库注明使用 Unsplash 图片。正式上线前请替换为公司拥有或已获授权的作品。
- `index.html` 中的 RS 为临时品牌名。`app.js` 的 `services` 中集中维护服务介绍。
- 由于尚未提供公司联系方式和接收咨询的后端，表单只整理和复制咨询内容，不会发送或存储用户信息。请配置真实接收渠道后再作为线上咨询入口。
- 材质节点区域根据家具业务重新绘制，替代参考视频的房地产地图。当前实现使用本地素材，不依赖图片 CDN。

支持小屏适配、键盘操作和减少动态效果偏好。不要把尚未提供的原站动画或公司项目当成已验证内容。

## 第二段视频的节奏融合

加入图片填充的 RE:NEW 大字与滚动缩放、三段箭头遮罩、逐行错拍标题、深色服务区域、悬停或聚焦时展开的背景图、滚动字切换，以及页脚大字浮现。动态跟随滚动进度；触屏通过点击打开服务详情，系统启用减少动态效果时不播放位移与缩放。

已在 Chromium 验证桌面 1440×900 与手机 390×844：图片加载、首屏展开、导航及 Escape、服务悬停和弹窗、服务自动选择、咨询内容生成、手机无横向溢出，以及减少动态效果。检查脚本运行于开发环境，未引入生产依赖。
